# Поступление — 2027 · Мой навигатор

Одностраничный справочник абитуриента по 11 вузам Москвы. Весь сайт находится в `index.html`, сторонние библиотеки и сборка не нужны.

## Как открыть

Скачайте репозиторий и откройте `index.html` в современном браузере.

## Как заполнить данными

В конце `index.html` найдите массив `UNIVERSITIES`. Для каждого вуза можно заполнить адрес, цену, бюджетные и платные места, проходные баллы за 2025/2026 годы, сведения о ВУЦ, даты дней открытых дверей, логистику, ссылку и дату проверки. Значения намеренно оставлены пустыми: цифры и условия необходимо сверять с официальными источниками.

Добавьте схемы маршрутов в корень рядом с `index.html` и укажите имя картинки в поле `routeImage` (например, `route_finuniversity.png`). Заметки в модальном окне сохраняются локально в браузере.

Журнал изменений настраивается в массивах `CHANGELOG` и `LAST_UPDATED`.
